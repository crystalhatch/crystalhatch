## Lightweight builds

Most of what's here started as a real problem that didn't need a full app. The pattern I keep coming back to: one source of truth, a thin display on top, and Claude doing the filing.

| Repo | What it is |
|---|---|
| [`sheet-powered-recipe-box`](https://github.com/crystalhatch/sheet-powered-recipe-box) | A recipe website that runs off a Google Sheet. Built to end the nightly "what's for dinner" decision fatigue. No app, no server, one 26 KB page. |
| [`personal-health-os`](https://github.com/crystalhatch/personal-health-os) | Three Claude skills for tracking training, food and recovery. |
| [`persona-builder`](https://github.com/crystalhatch/persona-builder) | A skill that interviews you and writes three files teaching Claude who you are, how you work and how you sound. |
